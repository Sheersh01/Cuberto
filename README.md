# Cuberto Website Clone

This project is a frontend web clone inspired by the [Cuberto](https://cuberto.com/) digital product agency website. It showcases a modern, dynamic, and highly interactive user interface.

## Features

- **Interactive Animations:** Powered by GSAP (GreenSock Animation Platform) and ScrollTrigger for smooth, scroll-based animations.
- **Advanced Mouse Effects:** Utilizes [Shery.js](https://github.com/aayushchouhan24/sheryjs) to create magnetic buttons, mouse followers, and image hover effects with media circles.
- **3D Graphics Integration:** Leverages Three.js for advanced visual effects.
- **Responsive Design:** Built with modern CSS to ensure the layout looks great across different devices.

## Technologies Used

- HTML5
- CSS3 (Custom styling and fonts)
- JavaScript
- [GSAP](https://greensock.com/gsap/) & [ScrollTrigger](https://greensock.com/scrolltrigger/)
- [Three.js](https://threejs.org/)
- [Shery.js](https://github.com/aayushchouhan24/sheryjs) (Built on top of Three.js and GSAP for epic WebGL effects)
- [Remix Icon](https://remixicon.com/) (For UI icons)

## Getting Started

To view this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Sheersh01/Cuberto.git
   ```
2. Open the project directory:
   ```bash
   cd Cuberto
   ```
3. Open `index.html` in your web browser, or use an extension like **Live Server** in VS Code to run the project.

The website features an interactive landing page, smooth scrolling sections, and a featured projects showcase with custom WebGL image effects.
